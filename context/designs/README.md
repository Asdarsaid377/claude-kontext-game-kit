# Designs: Referensi Visual

Folder ini adalah **source of truth visual**. Claude Code wajib mengecek folder ini sebelum membuat layar/komponen UI apapun (lihat `../ui-workflow.md`).

## Penamaan

- Per layar: `main_menu.png`, `level_select.png`, `gameplay.png`, `settings.png`
- Bagian spesifik: `gameplay-hud.png`, `gameplay-keyboard.png`
- Popup: `popup-level_complete.png`, `popup-pause.png`
- Ukuran layar berbeda: `gameplay-small.png`, `gameplay-tablet.png`
- Mood board / referensi gaya game lain: `ref-<nama>.png` (hanya acuan gaya, bukan untuk disalin)

## Aturan

1. Satu layar = minimal satu referensi sebelum dibangun
2. Desain berubah: ganti filenya, jangan menumpuk versi lama
3. Setelah token warna/font diekstrak, catat di `../ui-tokens.md`
